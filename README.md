# 綿雲ねむ おしながき — VTuber プロフィール LP のサンプル

架空の VTuber「綿雲ねむ」(夜ふかしの羊)のプロフィール LP です。Nokisaki Studio の出品「スマホで読みやすい1ページLP」の制作サンプルとして作りました。キャラクター・予定・ハッシュタグはすべて架空で、申込欄は送信されません。

実際のご依頼では、お手持ちの立ち絵と表情差分を、場所ごとの姿として使います。

## 見どころ

- **場所ごとに姿が替わる**: 広い画面では、横に立つねむが、読んでいる項目に合わせて持ち物と表情を替えます(手を振る → ゲーム機 → マイク → 枕 → 予定表 → 筆 → 眼鏡と書類)。狭い画面では、項目ごとに絵が並びます
- **同人イベントのお品書きの見た目**: 空色の紙に、青と蛍光ピンクの 2 色で刷ったリソグラフの風合い。ピンクの版が少しずれ、姿が替わる瞬間に大きくずれて戻ります
- **お品書きの部品**: 点線のリーダー、丸数字、ゴム印、休みの日の札、キリトリ線の申込欄

## 構成

表紙(名前・つぎの配信・予定とお仕事への入口)→ ① ゲーム実況 → ② 歌枠 → ③ 寝落ち雑談 → ④ 今週の予定と見られる場所 → ⑤ ファンアート・切り抜きのルール → ⑥ お仕事のご依頼(申込欄)→ 奥付。

## ファイル

- `index.html` — ページ本体。キャラの 7 つの姿は、ページの先頭に SVG の symbol として入っている(画像ファイルは使っていない)
- `styles.css` — 見た目。紙の繊維は SVG のノイズ、網点は CSS の点の繰り返しで描いている
- `app.js` — 動き。姿の切り替え(IntersectionObserver)と、申込欄の確認・受付票。ライブラリは使っていない

## 動きと読みやすさ

- OS の「視差効果を減らす/アニメーションを減らす」設定では、姿は替わるが弾まない
- 姿の変化は絵だけでなく、項目の見出しと札の文字でも伝わる
- 入力の誤りは送信時に表示し、直すと消える。完了は受付票に移り、そこへフォーカスが移る
- 文字は青(紙との色の差 5.7:1)。ピンクは文字には使わない。押せる所は 44px 以上

## 見かた

`index.html` をブラウザで開く。フォントは Google Fonts(Yusei Magic・Zen Kaku Gothic New)を読み込む。
